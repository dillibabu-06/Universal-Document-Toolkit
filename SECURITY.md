# Security Policy

## Supported Versions

Currently, only the latest release is actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Universal Toolkit OS. 

If you discover a vulnerability, **please do not open a public issue.** Instead, please send a private email to the project maintainers with the following information:
1. A description of the vulnerability.
2. Steps to reproduce the vulnerability.
3. Your system environment (OS, App version).

We will try to acknowledge your report within 48 hours and provide a timeline for a patch. We appreciate your efforts to responsibly disclose vulnerabilities!
